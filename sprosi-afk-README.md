# «Спроси AFK» — бот «Вопрос-ответ» для канала PC_AFK

<img src="sprosi-afk-avatar.png" width="140" align="right" alt="Аватарка бота">

Telegram-бот для канала [PC_AFK](https://t.me/pc_afk). Подписчики задают вопросы про ПК, бот за несколько секунд отвечает с помощью ИИ (Google Gemini с поиском в интернете) и в конце даёт короткий вердикт. Каждый вопрос уходит автору канала: лучшие он отмечает ⭐ и разбирает в рубрике «Вопрос-ответ».

- **Бесплатно:** хостинг на Cloudflare Workers, база в Cloudflare KV, ИИ на бесплатном тарифе Gemini.
- **Автономно:** работает круглосуточно на серверах Cloudflare, компьютер включённым держать не нужно.
- **Защищено:** антифлуд, проверка всех запросов, команды автора доступны только ему (подробнее в разделе «Безопасность»).

Файлы проекта:
- [`sprosi-afk-bot.js`](sprosi-afk-bot.js) — код бота;
- [`sprosi-afk-avatar.png`](sprosi-afk-avatar.png) — аватарка 640×640 для BotFather;
- [`sprosi-afk-avatar.svg`](sprosi-afk-avatar.svg) — её исходник.

## Что умеет

### Для подписчиков
- **Ответы ИИ на вопросы про ПК, железо и гаджеты:** что выбрать, как собрать, почему греется, стоит ли апгрейдиться. На вопросы не по теме бот вежливо отказывается отвечать.
- **Свежая информация.** Перед ответом ИИ ищет в Google актуальные данные про новинки и цены, а ещё знает сегодняшнюю дату, поэтому не рассуждает так, будто на дворе год его обучения.
- **Вердикт.** Каждый ответ заканчивается строкой `🏁 Вердикт: …` — одно предложение до 15 слов.
- **Мгновенная реакция.** Бот сразу пишет «🤔 Думаю над ответом…», а когда ответ готов, заменяет это сообщение на ответ.
- **Ответ всегда приходит.** Если ИИ не успел за 22 секунды или недоступен, бот всё равно отвечает «Принял вопрос!», а вопрос уходит автору.
- **Короткие понятные ответы** без лишней разметки, в дружелюбном стиле, с пометкой, что ИИ может ошибаться.
- **Команды** `/start` (приветствие) и `/help` (как правильно задать вопрос).

### Для автора канала
- **Уведомление о каждом вопросе:** кто спросил, сам вопрос и что ответил ИИ.
- **Кнопка ⭐ В рубрику** отмечает вопрос для видео. Повторное нажатие снимает отметку.
- **Личный ответ.** Если сделать **Reply** на уведомление, бот отправит этот текст человеку от имени автора. Если отправить не удалось, бот объяснит почему: например, человек заблокировал бота.
- **Заметки для ИИ.** Команда `/facts текст` сохраняет свои советы, цены и мнения о новинках, например: `/facts Сейчас лучшая карта за свои деньги — RTX 5060 Ti 16GB`. ИИ учитывает их в каждом ответе и ставит выше поиска и своих знаний. `/facts` без текста показывает текущие заметки, `/facts_clear` удаляет их.
- **Команды:**

| Команда | Что делает |
|---|---|
| `/list` | последние 20 вопросов |
| `/rubric` | вопросы, отмеченные ⭐ |
| `/stats` | сколько всего вопросов задано |
| `/facts` | показать, сохранить или заменить заметки для ИИ |
| `/facts_clear` | удалить заметки |

## Установка (≈20–30 минут, без командной строки)

### 1. Создать бота
1. В Telegram открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Имя: `Спроси AFK`, username, например, `sprosi_afk_bot` (если занят, придумай похожий).
3. Сохрани **токен**, который пришлёт BotFather, и никому его не показывай.

### 2. Получить ключ Gemini (бесплатно)
1. Зайди на [aistudio.google.com](https://aistudio.google.com) и нажми **Get API key** → **Create API key**. Из России сайт может не открыться без VPN.
2. Сохрани ключ.
3. Без ключа бот тоже работает, только без ответов ИИ: он просто собирает вопросы.

### 3. Узнать ID автора канала
Автор пишет боту [@userinfobot](https://t.me/userinfobot), тот отвечает числовым ID. Для теста можно сначала вписать свой ID, а потом заменить на ID автора.

Автор обязательно должен нажать **/start** в новом боте, иначе бот не сможет присылать ему вопросы.

### 4. Создать Worker в Cloudflare
1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com) (тариф Free, карта не нужна).
2. Открой **Workers & Pages** (в меню слева раздел **Compute & AI**, иногда просто **Compute**) → **Create application** → **Start with Hello World!** (или **Create Worker**).
3. Имя `sprosi-afk` → **Deploy**.
4. **Edit code**: удали всё, вставь содержимое `sprosi-afk-bot.js` → **Deploy**.

### 5. Подключить базу (KV)
1. **Storage & Databases** → **KV** → **Create** → имя `sprosi-afk`.
2. Открой Worker → **Bindings** (или **Settings** → **Bindings**) → **Add binding** → **KV namespace**.
3. Variable name: строго `DB` заглавными, namespace: `sprosi-afk` → **Add binding** / **Deploy**.

Предупреждение Cloudflare «Update your Wrangler configuration…» можно игнорировать: оно касается только тех, кто загружает код через командную строку.

### 6. Добавить переменные
Worker → **Settings** → **Variables and Secrets** → **Add**, после всех изменений нажми **Deploy**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от BotFather |
| `WEBHOOK_SECRET` | Secret | 8–256 символов: латиница, цифры, `_` и `-`, например `afkSecret2026qwe` |
| `ADMIN_ID` | Text | ID автора канала |
| `GEMINI_API_KEY` | Secret | ключ из AI Studio |
| `GEMINI_MODEL` | Text | необязательно; по умолчанию `gemini-flash-latest`, для быстрых ответов — `gemini-flash-lite-latest` (рекомендуется) |
| `DAILY_LIMIT` | Text | необязательно; вопросов в день на человека, от 1 до 100, по умолчанию `5` |
| `WEB_SEARCH` | Text | необязательно; `off` отключает поиск Google |

### 7. Включить бота
Открой страницу Worker'а: нажми на ссылку вида `sprosi-afk.что-то.workers.dev` в Cloudflare, и появится «Спроси AFK работает ✅». Допиши в адресной строке в конце `/setup?key=` и свой `WEBHOOK_SECRET`:

```
https://sprosi-afk.<твой-поддомен>.workers.dev/setup?key=<WEBHOOK_SECRET>
```

Если в ответе есть `"ok":true`, бот подключён. Напиши ему `/start` и задай вопрос.

### 8. Оформить бота в BotFather
`/mybots` → бот → **Edit Bot**:

- **Edit Botpic:** отправь `sprosi-afk-avatar.png` как фото.
- **Edit Description** (видно до нажатия «Старт»):
  ```
  Спроси AFK — бот канала PC_AFK 🖥

  Задай любой вопрос про ПК: что выбрать, как собрать, почему греется, стоит ли апгрейдиться. ИИ ответит за пару секунд и даст короткий вердикт, а лучшие вопросы автор разберёт в рубрике «Вопрос-ответ» 🎬

  Канал: @pc_afk
  ```
- **Edit About** (в профиле бота, до 120 символов):
  ```
  Вопросы про ПК и железо — ответ ИИ с вердиктом за секунды. Бот канала @pc_afk 🖥
  ```

### 9. Добавить бота в канал
Ссылку на бота можно поставить в описание канала, в закреплённый пост («Задай вопрос → @sprosi_afk_bot») или в конец роликов рубрики.

## Передача бота автору канала

**Что делает автор:**
1. Присылает свой ID (через [@userinfobot](https://t.me/userinfobot)). Его нужно вписать в `ADMIN_ID` и нажать **Deploy**.
2. Нажимает **/start** в боте.
3. Проверяет, что у него в BotFather меньше 20 ботов.

**Что делает владелец:**
1. Включает облачный пароль (двухэтапную аутентификацию) в Telegram: **Настройки** → **Конфиденциальность** → **Облачный пароль**. Он должен быть включён не меньше **7 дней**, а устройство авторизовано не меньше 24 часов.
2. В @BotFather: `/mybots` → бот → **Transfer Ownership** → **Choose recipient** → username автора → подтверждение паролем.

Токен при передаче не меняется, и Worker продолжит работать на аккаунте Cloudflare, где его создали. Новому владельцу **нельзя** нажимать **Revoke current token**, иначе бот перестанет работать, пока новый токен не впишут в `BOT_TOKEN`.

## Безопасность

- Обращаться к боту может только Telegram: каждый запрос проверяется по секретному заголовку, а секреты сравниваются за постоянное время. Если `WEBHOOK_SECRET` не задан или короче 8 символов, бот не запустится.
- Команды автора и кнопка ⭐ работают только для `ADMIN_ID`. Остальные видят ответ «Не знаю такой команды». Команды распознаются точно: `/factsXYZ` не сработает как `/facts`.
- Защита от флуда: один вопрос за раз, не чаще раза в 15 секунд и не больше `DAILY_LIMIT` в день. Если в лимит вписано не число, он не отключается, а возвращается к значению 5.
- Повторная доставка одного и того же сообщения от Telegram не создаёт второй ответ.
- Бот работает только в личных сообщениях: группы и другие боты игнорируются.
- Вопрос пользователя передаётся ИИ как данные, а не как инструкции: ИИ не меняет роль по просьбе пользователя и не пересказывает свои настройки.
- Сообщения отправляются без разметки, поэтому подменить форматирование или вставить кнопки через текст вопроса нельзя.
- При сбое Telegram, Gemini или базы пользователь получает понятное сообщение, а не тишину. Токен бота в логи не попадает.
- Вопросы и имена пользователей хранятся 180 дней и затем удаляются автоматически. Об этом сказано в `/help`.

## Ограничения бесплатного тарифа

- **Cloudflare KV:** около 1000 записей в день. Один вопрос — примерно 5 записей, то есть до ~200 вопросов в день.
- **Антифлуд** работает в памяти Worker'а. При очень большой нагрузке Cloudflare может запустить несколько копий, и тогда антифлуд работает внутри каждой копии отдельно. Дневной лимит в базе при этом всё равно действует.
- **Gemini:** лимиты и модели меняет Google. Если лимиты закончатся или поиск станет недоступен, бот ответит без поиска или просто примет вопрос.
- **Telegram в России** может работать с ограничениями. Сам бот при этом работает, но подписчикам может понадобиться VPN.

## Если что-то не работает

| Что видишь | Что значит и что делать |
|---|---|
| Ошибка сертификата при открытии `/setup` | Новый адрес `workers.dev` ещё получает сертификат: подожди 5–15 минут. Проверь дату и время на компьютере, попробуй мобильный интернет или VPN. |
| `forbidden` | Ключ в ссылке не совпадает с `WEBHOOK_SECRET`. Пересоздай переменную с простым значением, нажми **Deploy** и вставь то же значение в ссылку. |
| `429 Too Many Requests` | Telegram просит подождать секунду. Обнови страницу. |
| `Webhook is already set` | Всё хорошо, бот уже подключён. |
| `401 Unauthorized` или `404 Not Found` при проверке токена | Токен в ссылке набран неверно или перевыпущен. Возьми актуальный в BotFather → **API Token**, обнови `BOT_TOKEN` и снова открой `/setup`. |
| Бот молчит | Напиши `/start`. Если молчит и на него, открой `/setup` ещё раз и проверь `BOT_TOKEN` и привязку `DB`. |
| «ИИ не ответил» / «ИИ сейчас отдыхает» | Проверь `GEMINI_API_KEY` и укажи в `GEMINI_MODEL` значение `gemini-flash-lite-latest`. |
| Отвечает слишком долго | Поставь `GEMINI_MODEL` = `gemini-flash-lite-latest`. |
| ИИ даёт устаревшую информацию | Проверь, что `WEB_SEARCH` не равен `off`. Добавь свои актуальные заметки через `/facts`. |
| Автору не приходят вопросы | Автор должен нажать `/start` в боте, а `ADMIN_ID` должен совпадать с его ID. |
| «Что-то пошло не так» | Посмотри ошибку в Worker → **Logs** / **Observability** → **Begin log stream**. |

## Обновление кода
Cloudflare → `sprosi-afk` → **Edit code** → удали всё → вставь новую версию `sprosi-afk-bot.js` → **Deploy**. Переменные, база и вебхук сохраняются, `/setup` открывать заново не нужно.
