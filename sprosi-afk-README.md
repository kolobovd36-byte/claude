# «Спроси AFK» — бот «Вопрос-ответ» для канала PC_AFK

Telegram-бот для канала [PC_AFK](https://t.me/pc_afk). Подписчики задают вопросы про ПК, бот сразу отвечает с помощью ИИ (Google Gemini) и пересылает вопрос автору канала. Лучшие вопросы автор отмечает ⭐ и разбирает в рубрике «Вопрос-ответ».

**Работает бесплатно:** хостинг на Cloudflare Workers, база в Cloudflare KV, ИИ на бесплатном тарифе Gemini.

Код бота: [`sprosi-afk-bot.js`](sprosi-afk-bot.js)

## Что умеет

**Для подписчиков**
- `/start` и `/help`: приветствие и подсказки, как задать вопрос
- ответ ИИ на любой вопрос про ПК, железо и гаджеты (на вопросы не по теме бот вежливо отказывается отвечать)
- лимит вопросов в день (по умолчанию 5), чтобы не превысить бесплатный тариф ИИ
- если ИИ недоступен, вопрос всё равно сохраняется и уходит автору

**Для автора канала**
- уведомление о каждом вопросе: кто спросил, сам вопрос и ответ ИИ
- кнопка **⭐ В рубрику**, чтобы отметить вопрос для видео
- **Reply** на уведомление отправляет человеку личный ответ от имени бота
- `/list` показывает последние вопросы, `/rubric` — отмеченные ⭐, `/stats` — сколько всего вопросов

## Установка (≈20 минут, без командной строки)

### 1. Создать бота
1. В Telegram открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Имя: `Спроси AFK`, username, например, `sprosi_afk_bot` (если занят, придумай похожий).
3. Сохрани **токен**, который пришлёт BotFather.
4. По желанию: `/setdescription` и `/setuserpic` (аватарка в стиле канала).

### 2. Получить ключ Gemini (бесплатно)
1. Зайди на [aistudio.google.com](https://aistudio.google.com) и нажми **Get API key** → **Create API key**.
2. Сохрани ключ. Из России сайт может не открыться без VPN.
3. Без ключа бот тоже работает, только без ИИ-ответов: просто собирает вопросы.

### 3. Узнать ID автора канала
Автор канала пишет боту [@userinfobot](https://t.me/userinfobot), тот отвечает его числовым ID. После этого автор должен нажать **/start** в новом боте, иначе бот не сможет присылать ему уведомления.

### 4. Создать Worker в Cloudflare
1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com) (тариф Free).
2. **Workers & Pages** → **Create** → **Worker** (шаблон Hello World) → имя `sprosi-afk` → **Deploy**.
3. **Edit code**: удали всё, вставь содержимое `sprosi-afk-bot.js` и нажми **Deploy**.

### 5. Подключить базу (KV)
1. **Storage & Databases** → **KV** → **Create** → имя `sprosi-afk`.
2. Открой Worker → **Settings** → **Bindings** → **Add** → **KV namespace**.
3. Variable name: `DB`, namespace: `sprosi-afk` → **Deploy**.

### 6. Добавить переменные
Worker → **Settings** → **Variables and Secrets** → **Add**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от BotFather |
| `WEBHOOK_SECRET` | Secret | любая строка из латиницы и цифр, например `afkSecret2026qwe` |
| `GEMINI_API_KEY` | Secret | ключ из AI Studio |
| `ADMIN_ID` | Text | ID автора канала |
| `DAILY_LIMIT` | Text | необязательно, по умолчанию `5` |
| `GEMINI_MODEL` | Text | необязательно, по умолчанию `gemini-flash-latest` |

### 7. Включить бота
Открой в браузере адрес (подставь свой поддомен и секрет):

```
https://sprosi-afk.<твой-поддомен>.workers.dev/setup?key=<WEBHOOK_SECRET>
```

Если в ответе есть `"ok":true`, бот готов. Напиши ему вопрос и проверь.

### 8. Добавить бота в канал
Ссылку на бота можно поставить в описание канала, в закреплённый пост («Задай вопрос → @sprosi_afk_bot») или в конец роликов рубрики.

## Если что-то не работает
- **Бот молчит.** Ещё раз открой ссылку `/setup` и проверь `BOT_TOKEN` и привязку `DB`.
- **Отвечает «ИИ сейчас отдыхает».** Проверь `GEMINI_API_KEY`. Если ошибка про модель, укажи в `GEMINI_MODEL` актуальную модель из AI Studio.
- **Автору не приходят вопросы.** Он должен нажать `/start` в боте, а `ADMIN_ID` должен совпадать с его ID.
- **Логи:** Worker → **Logs** (Real-time logs).

## Передача бота
Бот можно передать автору канала через @BotFather → `/mybots` → **Transfer Ownership**. Для этого на аккаунте владельца облачный пароль должен быть включён не меньше 7 дней. Токен при передаче не меняется, а Worker продолжит работать на аккаунте Cloudflare, где его создали.
