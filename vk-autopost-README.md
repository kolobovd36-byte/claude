# VK автопостинг через Telegram (n8n)

Каждый день в 07:00 МСК бот присылает 2 готовых поста с фото. Под каждым кнопки:
✅ Опубликовать (сразу в группу ВК) · ✏️ Правка · 🖼 Другое фото · ❌ Отклонить (+ «Сделать другой пост»).

Команды: `/new` — сгенерировать посты сейчас, `/cancel` — отменить правку, `/start` — помощь.
В режиме правки: пиши текстом, что изменить; начни с «фото:», чтобы перерисовать картинку; или пришли своё фото.

## Установка
1. n8n → Workflows → **Import from file** → `vk-autopost-n8n.json`.
2. Узел **Telegram Trigger** → создай credential с токеном бота от @BotFather.
3. Узел **Настройки** → впиши `TG_TOKEN`, ключи нейросети (`LLM_API_KEY`, `IMAGE_API_KEY`) и `VK_USER_TOKEN`.
4. Включи workflow (Active), напиши боту `/start` — он пришлёт твой chat_id. Вставь его в `ADMIN_CHAT_ID`, сохрани.
5. Отправь `/new` для проверки.

## VK-токен
Нужен **пользовательский** токен админа группы с правами `wall, photos, groups, offline`
(токен сообщества не умеет загружать фото на стену). Проще всего — vkhost.github.io → Kate Mobile → скопировать `access_token` из адресной строки.

## Важно
- n8n должен быть доступен по HTTPS из интернета (облако n8n или свой сервер) — иначе Telegram не достучится до триггера.
- Черновики и история тем хранятся в static data воркфлоу (только в активном режиме), черновики старше 7 дней удаляются.
- Стиль постов — поле `STYLE_GUIDE` в узле «Настройки» (исходник: `vk-autopost-style.txt`, сборка: `python3 vk-autopost-build.py vk-autopost-style.txt vk-autopost-n8n.json`).
